    1004. 寻找两个有序数组的中位数

    给定两个有序数组 a 和 b，求合并后的中位数。算法的总时间复杂度应为 O(log (n + m))。

    输入格式

    第一行包含两个整数 n、m。接下来两行分别给出两个非递减数组。

    输出格式

    输出一个实数，表示两个数组合并后的中位数。

    样例

    输入
2 3
1 3
2 4 7

输出
3

    数据范围

    0 ≤ n, m ≤ 2 × 10⁵，并且 n + m ≥ 1。

    题目 / 1007
    最长上升子序列
    通过率 41.32% · 中等 · 动态规划
    一种耐心的策略：O(n log n)
    望月 · 2026-08-02 · 已验证
    证明思路
    设 f[i] 为长度为 i 的上升子序列的最小可能末尾值。保持每个位置尽可能小，就能为后续元素留下更多空间。
    不变量
    处理完前 k 个元素后，数组 f 严格递增，并且每个位置都是对应长度的最小末尾值。
    复杂度
    每个元素执行一次二分查找，因此时间复杂度为 O(n log n)，空间复杂度为 O(n)。
    参考实现
    int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;
    for (int x : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return static_cast<int>(tails.size());
}
