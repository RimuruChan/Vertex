## 浏览器与移动端

本轮在正常页面的 mock 模式使用实际浏览器交互和 DOM 几何测量，视口为 320×740、390×844、1440×900；不是物理手机、触摸键盘或 Safari 兼容性验收。

- 390px：题库、工作台列表/详情、比赛设置/编排、裁判台、题单、group、域成员/角色/标签/公告详情及归档设置均没有整页横向溢出。宽榜单/编辑表和工作台标签在自身容器内滚动。
- 工作台标签原先将 375px 内容区撑到 458px，修复后整页为 375px；八个标签可分别到达。测试点编辑弹窗和题单选题弹窗左右边界约为 16–359px，内容没有横向溢出；关闭时未保存任何修改。
- 320px 做题页原先按固定 64px 页头计算，内容底部到 842px，超过 740px 视口。页头改为实测高度，收紧窄屏标识后，页面高度为 740px，代码区底部约 731px，语言/模板/提交入口可达。移动导航展开后聚焦首项，栏目链接可用。
- 语言菜单的已有 scrollbar-gutter 修复仍有效：390px 下编辑器 x≈34.4、宽≈306.4，1440px 下 x≈442.8、宽≈875.2；菜单开关前后横坐标和宽度不变。切换 Python 后恢复 C++，未保存题目包。
- 训练域工作台列表的次要状态在小屏移到标题下方，入口保留可访问名称；同一份 12 题列表的页面高度由约 3494px 降到 1494px。无创建权限时，不再建议用户创建无法创建的题目。
- 题单标题原先越过单元格边界约 67px，覆盖后续统计列。小屏统计改为标题下的辅助信息，标题右边界位于自己的单元格内；桌面仍保留统计列，编辑状态只局部横向滚动。
- 实际切换六种账号：普通账号在官方域禁用新建、在训练域可新建；观察员没有答疑写入入口，裁判有公告入口；选手无设置/协作/裁判台入口，未开赛比赛不返回题目清单。
- 比赛题地址 `/d/official/contests/1/problems/A` 只有题面/代码/结果，不挂载题解或普通讨论。切换域返回 `/d/training/contests`，没有携带原比赛号。访客只能选择公开域，直接访问私域显示拒绝、登录和返回官方域入口。
- 归档域的四个设置字段实际匹配 `:disabled`，恢复按钮仍可用；复制目标列表排除归档域。加载失败显示明确错误/重试，不伪装为空列表，正常模式切回后可恢复。

前期创建、保存、测试数据、模拟构建/发布、协作/撤销、独立副本及社区回复的写入证据保留在实施计划 P0、P2g、P3b–P3f。本轮未新建、删除或修改已有演示资源；原官方 12 题、训练题库、比赛与群组保留，既有 QA 域保持归档。最终恢复 `admin_demo`、正常加载、官方工作台及桌面视口。

- `go -C server vet ./...` 与 `go -C server test ./... -count=1` 通过，真实 PostgreSQL 套件及 `TestDomainAPIIntegration` 实际运行；`go -C worker vet ./...` 与全量 test 通过。

- 本阶段逐项审阅了代码 diff、各阶段签名记录与需求证据；README、架构、数据库、API、社区/路线图同步实际域模型，并移除必须删除旧卷才能更新的误导。
