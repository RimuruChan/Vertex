# 题面写作与资源交互优化

日期：2026-09-21。先提交上一轮工作区 UI（9154b43），再独立推进这一轮题面优化。

## 编辑器调研

| 方案 | 官方能力 | 本项目取舍 |
| --- | --- | --- |
| [CodeMirror 6 Markdown](https://github.com/codemirror/lang-markdown) | Markdown / GFM 语法、列表续写、代码块语言、搜索与历史可组合 | 本轮采用。直接编辑原始文档，不引入源码与富文本之间的转换，继续使用既有保存、版本和冲突机制。 |
| [Milkdown](https://github.com/Milkdown/milkdown) | 基于插件的所见即所得 Markdown 编辑框架 | 借鉴面向写作的工具和内容插入体验。接入可视化编辑前，需验证公式、自定义题包语法、嵌入内容往返转换，不能只验证普通段落。 |
| [Tiptap Markdown](https://tiptap.dev/docs/editor/markdown) | Markdown ↔ JSON 文档转换；官方当前标注 Beta 并列出限制 | 暂不把已导入的源码经 JSON 重建。它适合结构化内容，但不能据此假设题包原文会逐字保留。 |
| [Monaco](https://github.com/microsoft/monaco-editor#faq) | VS Code 同源代码编辑器，模型、语言服务、编辑历史 | 更适合代码工作区。其官方 FAQ 明确未支持移动浏览器，因此本轮不替换共享编辑器。 |

表格中的取舍是结合项目数据与交互要求的判断，不是对编辑器能力的通用排名。

## 本轮交互

- 写作 / 对照 / 预览：宽屏左右对照，窄屏上下对照；大纲在窄屏覆盖编辑区，不继续挤窄文本。
- 真正的 Markdown 与 TeX 语言支持，保留源码；标题、列表按完整行操作。
- 撤销、重做、搜索替换、加粗与斜体快捷键；常用章节、代码块、表格插入。
- 公式使用独立 / 行内选择，输入时预览排版，确认后插入光标位置。
- 图片与附件直接在题面中搜索、选择、预览或上传；上传后确认插入，不自动放到文末。
- 新上传附件使用系统位置，展示原文件名；Markdown / TeX 引用自动生成。公开附件才出现在题面资源选择器。
- 附件上传前保存当前题面；上传和工作副本更新沿用版本前置条件，失败保留输入，不覆盖另一页面的副本。
- 全屏时弹窗和插入菜单渲染在全屏容器内。

## 材料交互原则

材料名称与存储位置分离。新建只选名称、用途与语言；路径由系统生成并检测重名、大小写冲突和目录被文件占用。已导入文件不批量搬家，避免破坏源码 include、TeX 和 Markdown 相对引用。

程序引用按名称选择，选中源文件后推导工作目录，已有导入根目录仍适用时保留。上传整个程序文件夹保留其内部布局，每次上传放入独立批次，避免不同程序同名源码冲突。

普通列表、附件检查器、题面操作和新建表单不再要求编辑文件路径。手工合并中的位置选择改为自动整理 / 沿用我的布局 / 沿用共享布局。导入兼容报告、原始源码和冲突诊断中仍可能出现题包原始路径；这些是诊断信息，不是要求用户填写的配置。

## 后续边界

这轮没有把题面拆成多个强制表单字段，也没有引入实时多人编辑或富文本转换。TeX 仍需通过现有检查流程编译完整 PDF，公式局部预览不代表完整 TeX 编译结果。样例与题面联动可以在后续迭代继续优化。

## 程序与题面入口的进一步重做

用户反馈指出，移除路径输入没有解决“程序配置 + 全局源文件 + 手动关联”的错误交互模型。程序现在作为完整的编辑对象：

- 打开程序直接编辑主代码，用途说明随程序显示。创建程序同时创建主代码，使用一个工作副本事务保存。
- 多文件是程序内部的代码标签；标签点击即打开代码，有明确选中下划线和主代码标识。添加辅助代码自动加入当前程序，不再要求点击不明含义的关联按钮。
- 移除全局源码目录树和独立的入口文件选择器。设置位于独立面板，程序用途使用有说明的单选卡片，预期结果使用带勾选框的选项。
- 导入多文件程序保留内部相对布局。编辑共享源码时复制整个程序布局，保护其他程序；辅助代码重名时整理布局，保留 include/import 所需的文件名。旧版本和未归属资料仍可恢复，不直接删除。
- 代码与配置通过同一个副本版本前置条件保存，任何上传失败都不会写入部分程序。
- 题面上方散开的语言、添加语言、格式、保存按钮行合入编辑器顶栏。语言菜单同时提供切换和新增入口，保存以状态反馈，手动保存放在更多操作中；格式工具保留一行。

验证涵盖真实后端新建程序、添加辅助代码、切换并编辑、保存预期结果、重新读取；单元测试覆盖原子保存、上传失败、共享源码隔离和文件名冲突下的相对引用保真。
