# 出题工作台交互重设计

本轮针对旧前端直接暴露材料对象、操作分散、控件使用繁琐的问题，重做前端交互。沿用现有后端的私人副本、CAS、提交、检查和发布边界，没有修改后端协议或数据库。

## 操作组织

- 侧栏按编写、版本与交付、工具与设置分组；更改/历史归入版本管理，检查/发布归入交付流程，保留真实路径。
- 基本设置按题目信息、运行限制、判定方式、质量检查和授权分区；内存使用 MiB，程序按用途筛选并显示名称。高级参数折叠，数字错误贴近字段，标签可以连续输入逗号。
- 题面改为 CodeMirror 工作区，提供格式工具栏、编辑/分屏/预览与全屏；去掉 textarea 原生缩放角。手机使用单栏，隐藏不必要的文件操作。切换工作区前先尝试保存。
- 数据上传按同名 .in/.out/.ans 自动配对，先确认再通过一次 CAS 保存文件、测试描述及顺序；手动添加直接填写输入/答案。测试点侧栏直接读写数据，生成方式等留在高级设置。未完成添加不能无提示关闭。
- 附件分为公开附件与内部资料，提供文件卡片、预览、下载、移除和插入题面；支持 Markdown 链接和 TeX 图片，题面预览通过授权 blob 显示图片。
- 更改页使用文件清单与差异区，提交说明放在顶部；结构化设置显示中文字段变化，小文本数据可直接比对，原始文件仍可下载查看。
- 发布按选提交、核对检查、创建发布三步推进，缺少检查可原地开始并跟踪，离开再返回时恢复进行中的任务。支持实际已接通的 TeX/PDF 发布。
- 导入导出分开操作；导入选择文件后自动预检，导出先选择完整备份/数据/平台交付，再显示相应格式选项。

## 本轮验证

- 50 个前端测试文件、223 项测试通过；生产/mock 构建和格式检查通过。
- 新测试覆盖文件配对、歧义拒绝、原子保存、失败不写入部分测试、字段校验、链接转义与字段差异。
- 真实浏览器走过手动测试和成对上传、附件预览/插入、提交 r3、运行真实检查并发布本地测试题 v2；测试发生在任务专用域。
- Markdown 工具栏与实时预览工作正常；无效时间值显示本地错误，恢复后可保存；输入标签后切页保存，重新打开能读到两个标签。
- 桌面、768px 与390px布局检查；亮暗主题检查。主题和视口已恢复。
